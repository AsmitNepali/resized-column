The entries below cover the most common issues. For anything else, open an issue on [GitHub](https://github.com/AsmitNepali/resized-column/issues).

## Resize handles not showing / styles broken

The package's CSS and JS are served through Filament's asset system. If handles are missing or misaligned:

1. Publish the assets:
   ```bash [Terminal]
   php artisan filament:assets
   ```
2. Hard-refresh the browser (Ctrl/Cmd + Shift + R) to clear cached assets.

Re-run `php artisan filament:assets` after every package update, too.

## Widths/order not persisting across devices

Session storage is per browser/device by design. To persist for the same user everywhere, switch to database storage:

1. `->preserveOnDB()` on the plugin (or `standalone()` / the table macro — see [Storage](/essentials/storage#configuration-priority)).
2. Publish and run the migration:
   ```bash [Terminal]
   php artisan vendor:publish --provider="Asmit\ResizedColumn\ResizedColumnServiceProvider" --tag=resized-column-migrations
   php artisan migrate
   ```

## `preserveColumnWidthsInDatabase()` seems to do nothing

The table macro must be the **last** call in the `table()` chain. If it runs before the Livewire component reference is resolved, it can't wire up. Move it after `->columns()`, `->filters()`, `->actions()`, and everything else. See [Standalone usage → Option B](/essentials/standalone-usage#option-b-per-table-via-table-macro).

## Can't drag a pinned column

That's expected. Sticky columns are excluded from reordering, and a column can't be dropped before a sticky one. See [Reordering columns](/essentials/reordering-columns#interaction-with-sticky-columns).

## Reordering doesn't work with column groups

Reordering supports flat column tables only — column groups aren't supported in the current version.

## Column won't pin to the right

Sticky is left-pin only right now. Right-pinning isn't supported yet — see [Sticky columns](/essentials/sticky-columns#limitations).

Still stuck? [Open an issue](https://github.com/AsmitNepali/resized-column/issues).
