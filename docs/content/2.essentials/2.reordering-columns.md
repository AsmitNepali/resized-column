Drag-to-reorder is **opt-in per table**. Chain `->dragReorderableColumns()` on the table to turn it on.

## Enable it

```php
public function table(Table $table): Table
{
    return $table
        ->columns([
            TextColumn::make('name'),
            TextColumn::make('email'),
        ])
        ->dragReorderableColumns();
}
```

A grip handle appears on each column header. Drag it to move the column; the new order is persisted per user and reapplied on load. Reordering uses [SortableJS](https://sortablejs.github.io/Sortable/) under the hood.

## Interaction with sticky columns

::callout{icon="i-lucide-alert-triangle" color="warning"}
- Sticky (pinned) columns are **excluded from dragging** — you can't drag a pinned column.
- A column **cannot be dropped before a sticky one** — pinned columns stay anchored to the edge.
::

## Limitations

- Reordering currently supports **flat column tables** — column groups are not supported.

## Persistence

The column order is stored in the same per-user record as widths and pinned columns. See [Storage](/essentials/storage) to control whether that record lives in the session or the database.
