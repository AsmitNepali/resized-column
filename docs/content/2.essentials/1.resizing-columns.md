Resizing is the core feature and the only one that's on by default once you add the trait.

## Enable it

Add `HasResizableColumn` to the page (List page, custom page, or standalone Livewire component) that renders the table:

```php
use Asmit\ResizedColumn\HasResizableColumn;
use Filament\Resources\Pages\ListRecords;

class ListUsers extends ListRecords
{
    use HasResizableColumn;

    protected static string $resource = UserResource::class;
}
```

Every column on that table gets a draggable right edge. No per-column opt-in is required.

## How it works

- A drag handle is added to each column header by the package's JS (published via `php artisan filament:assets`).
- On drop, the new width is sent to the server and stored for the current user.
- On the next load, stored widths are read back and applied before the table renders.

Widths, column order, and pinned columns are all kept in **one persisted record per user** — see [Storage](/essentials/storage) for where that record lives.

## Customizing persistence

Override any of these methods on your page/component class to change how widths are saved and loaded:

| Method | Description |
| --- | --- |
| `persistColumnWidthsToDatabase()` | Customize how column widths are saved to the database |
| `persistColumnWidthsToSession()` | Customize how column widths are saved to the session |
| `loadColumnWidthsFromDatabase()` | Customize how column widths are loaded from the database |
| `loadColumnWidthsFromSession()` | Customize how column widths are loaded from the session |
| `getUserId()` | Customize how the current user is identified |

### Example — custom database storage

```php
use Asmit\ResizedColumn\HasResizableColumn;

class ListUsers extends ListRecords
{
    use HasResizableColumn;

    protected function persistColumnWidthsToDatabase(): void
    {
        YourCustomModel::updateOrCreate(
            [
                'user_id'  => $this->getUserId(),
                'resource' => $this->getResourceModelFullPath(), // e.g. 'App\Models\User'
            ],
            ['settings' => $this->columnWidths],
        );
    }
}
```

## Troubleshooting

If resize handles don't appear or look broken, re-run `php artisan filament:assets` and hard-refresh the browser. Full checklist in [Troubleshooting](/troubleshooting).
