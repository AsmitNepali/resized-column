## Quick Start

1. **Fork** the repository
2. **Create** a feature branch
3. **Make** your changes
4. **Submit** a pull request

## Guidelines

- Follow the existing code style
- Keep pull requests focused — one feature or fix per PR
- Update the docs when behavior changes

## Security

If you discover a security vulnerability, please email **asmitnepali99@gmail.com** instead of opening a public issue. All reports are addressed promptly.

## Need Help?

- [Open an issue](https://github.com/AsmitNepali/resized-column/issues) for bugs or questions
- Check [existing issues](https://github.com/AsmitNepali/resized-column/issues) first
