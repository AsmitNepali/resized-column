## Requirements

- **PHP** 8.1+
- **Laravel** 10, 11, or 12
- **Filament** 3, 4, or 5 (`filament/support` `^3.2|^4.0|^5.0`)

## Install the package

```bash [Terminal]
composer require asmit/resized-column
```

The service provider `Asmit\ResizedColumn\ResizedColumnServiceProvider` is auto-discovered — no manual registration needed.

## Register the panel plugin

Add the plugin to your panel provider (`app/Providers/Filament/AdminPanelProvider.php`):

```php
use Asmit\ResizedColumn\ResizedColumnPlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        // ... other configuration
        ->plugins([
            ResizedColumnPlugin::make()
                ->preserveOnDB(), // optional — enable database storage
        ]);
}
```

::callout{icon="i-lucide-info" color="info"}
Not using a panel? The trait works in any standalone Livewire table too. See [Standalone usage](/essentials/standalone-usage).
::

## Publish the Filament assets

The package ships CSS and JS through Filament's asset system. Publish them after install and after each update:

```bash [Terminal]
php artisan filament:assets
```

## Publish and run migrations (optional)

Only needed if you enable **database storage** (`->preserveOnDB()`). Session storage requires no migration.

```bash [Terminal]
# Publish the migration
php artisan vendor:publish --provider="Asmit\ResizedColumn\ResizedColumnServiceProvider" --tag=resized-column-migrations

# Run it
php artisan migrate
```

This creates the `table_settings` table — one row per user holds column widths, order, and pinned columns together.
