The smallest path: add one trait to a List page, refresh, drag a column edge. Then opt into reordering and pinning as you need them.

## Prerequisites

- Package installed and plugin registered — see [Installation](/getting-started/installation).
- Filament assets published (`php artisan filament:assets`).
- A Filament resource with a List page (this guide uses `UserResource`).

## Step 1 — Add the trait

Add `HasResizableColumn` to your List page (or any custom page hosting a table):

```php [app/Filament/Resources/UserResource/Pages/ListUsers.php]
use Asmit\ResizedColumn\HasResizableColumn;
use Filament\Resources\Pages\ListRecords;

class ListUsers extends ListRecords
{
    use HasResizableColumn;

    protected static string $resource = UserResource::class;

    // Your existing table definition...
}
```

That's it — every column on that page is now resizable. Drag a column's right edge to change its width.

## Step 2 — Verify persistence

Resize a column, then reload the page. The width is restored.

By default it's stored in the **session** (per browser/device). To persist across devices for the same user, enable database storage on the plugin and run the migration — see [Storage](/essentials/storage).

## Step 3 — Add reordering and pinning (optional)

Chain the table macros to let users drag-reorder and pin columns:

```php
public function table(Table $table): Table
{
    return $table
        ->columns([
            TextColumn::make('name')->sticky(), // pinned by default
            TextColumn::make('email'),
            TextColumn::make('created_at'),
        ])
        ->dragReorderableColumns()  // grip handle to reorder
        ->stickableColumns();       // "Pin columns" toolbar dropdown
}
```
