---

Add the `HasResizableColumn` trait to your Filament List page or custom page class. This enables the resizable column feature for all tables on that page.

```php
use Asmit\ResizedColumn\HasResizableColumn;

class ListUsers extends ListRecords
{
    use HasResizableColumn;

    protected static string $resource = UserResource::class;

    // Your existing table definition...
}
```

Once the trait is in place, every column becomes resizable. See the [features overview](/features/overview) for everything you can enable — [reordering](/features/reordering), [sticky columns](/features/sticky-columns), [storage](/storage), and more.
